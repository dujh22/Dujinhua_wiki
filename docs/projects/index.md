## 报告结构说明

每份报告均包含以下 10 个固定章节：

| 章节 | 内容 |
|---|---|
| 1. 项目概述（Abstract） | 一句话定位 + 核心成果量化 |
| 2. 背景与动机（Introduction） | 问题定义、行业背景、启动契机 |
| 3. 相关工作（Related Work） | 同期/前人工作对比、差异化定位 |
| 4. 方法与技术路线（Method） | 技术方案、Pipeline、算法设计、架构 |
| 5. 实验与结果（Experiments） | 数据集、评估指标、具体数字、对比/消融实验 |
| 6. 工程实现（Engineering） | 代码仓库、部署、算力、工具链 |
| 7. 成果与影响（Impact） | 论文/专利/开源/产业应用/获奖 |
| 8. 个人贡献（My Contribution） | 角色定位、具体工作、团队分工 |
| 9. 经验与反思（Lessons Learned） | 问题、解决方案、可复用方法论 |
| 10. 文件索引（References） | 飞书文档链接、GitHub仓库、论文链接 |
